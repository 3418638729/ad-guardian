# 截图目录

主 README 的「界面」一节引用了下面三张图。**文件名必须完全一致**，
否则图片会显示为裂图。

| 文件名 | 拍什么 | 要求 |
|---|---|---|
| `check.png` | 正常状态，五项全绿 | 完整显示五项检测结果 |
| `broken.png` | GKD 无障碍被关掉时的样子 | 要有红色/警示那一行 |
| `fix.png` | 点「修复」后的跳转提示 | 能看到是跳到哪一页 |

拍摄建议：

- 手机截图直出，不要用另一台手机拍屏幕
- 宽度 1080px 左右即可，不用放大
- 🚫 **打码**状态栏里的手机号、运营商、通知内容
- 三张图的风格统一（同一台手机、同一套主题）

放好之后，把主 `README.md` 里「界面」一节的注释标记去掉即可。
